# P3-3 共享计划设计草案

状态：用户已确认 D10、D11 和下列产品默认值。需求依据为仓库内 V1 摘录 §28–31。

## 1. 用户流程和权限

- 同一空间的任一成员可创建共同活动，初始为 `Want`。商品、礼物和购物清单不在范围内。
- 双方都可单独执行 `Want → Plan` 和 `Plan → Finished`。D10 建议只允许这两步。日期、时间、地点和备注均可留空，状态推进不改变正文。
- 正文包括标题及上述详情。创建者直接修改，伴侣通过编辑请求提交完整建议。D11 建议日期、时间、地点和备注也走该规则。待处理请求最多一条，期间暂停创建者直接编辑，双方仍能推进状态。创建者批准或拒绝，提议者可撤回。双方可在详情中查看最近一次处理结果。
- 建议日期和时间使用空间的 `Asia/Shanghai` 本地值，填时间时要求同时填日期。字段长度在首批接口契约中明确。完成后仍可按相同权限更正正文。
- 建议完成后双方均可关联同空间已有回忆，或创建并关联一条回忆。每个计划最多关联一条，首批无换绑和解除入口。关联保持回忆原归属及照片权限。通知、删除、恢复和成就统计另行评审。

## 2. 数据、接口与一致性

- 使用计划根表、正文修订、编辑请求及决定、状态事件、回忆关联。历史数据追加写入。同空间约束覆盖计划、请求、决定与回忆关系。正文与状态各有自己的版本。审批只比对正文版本，状态事件不使请求失效。
- 接口覆盖列表、详情、创建、正文修订、请求及决定、状态推进。列表按不可变的创建时间和 ID 做游标分页。详情同时返回当前正文、状态、待处理请求及最近处理结果。跨空间及猜测 ID 的读取和写入统一返回 404。
- 变更在事务内按调用方与操作分类幂等键，校验规范化请求指纹。重放返回原操作事实与当前状态。状态推进携带预期源状态，避免一次迟到的请求继续推进到下一步。数据库守卫拒绝跳跃、回退、跨空间关联和不符合审批内容的修订。
- 先锁定有效成员，再取计划锁，然后分类、检查权限及当前版本、写入事实和审计。创建并关联回忆应使用现有回忆写入规则，在同一事务提交回忆、照片绑定和关联。实现前核对现有事务入口及锁顺序，再确定计划锁与回忆、媒体锁的顺序；禁止跨两笔事务拼接。
- 仓库迁移目前止于 `0032`。下一迁移候选为 `0033`，实施前重查迁移号、锁编号和错误码。保持已冻结迁移原字节。

## 3. 实施批次与验收

1. **P3-3a 计划后端。** 迁移、权限、接口契约和隔离验证。覆盖双方创建和状态推进、跨空间拒绝、正文审批三种结局、状态推进与审批并发、双请求竞争、同键重放与异体冲突、分页。先做回滚预检，再在一次性数据库应用并验证重复执行、权限和后端回归。
2. **P3-3b 回忆关联后端。** 覆盖未完成计划与跨空间拒绝、已有回忆关联、创建并关联的原子回滚、同键重放、双成员同时关联只保留一个结果、照片授权不扩张。先使用模拟对象存储。
3. **P3-3c 网页与验收。** 实现列表、详情、状态操作、审批和关联。未确认写入保留原键与请求，账号变化丢弃迟到结果。先跑前端自动化，再做隔离双账号浏览器验收。真实服务、设备和联合发布各自记录证据。

## 4. P3-3a 实现

`0033_shared_plans` 使用计划根表与统一追加事件表。事件同时记录请求与原始回执；批准事件承载获批正文和正文版本，从结构上避免审批决定与正文分别提交。幂等比较使用 PostgreSQL 解析后的 JSON 值，同一调用方、操作和键的写入先取 33023 键锁，再取 33022 计划锁。状态与正文版本独立。

接口契约为 0.28.0。标题长度为 1–80，地点最多 120，备注最多 2000。详情字段通过显式空值表示未填写，时间使用空间本地的 `HH:mm`，且必须有日期。首批不写入回忆关联。

## 5. P3-3b 回忆关联

- `POST /api/v1/shared-plans/{planId}/memory-link` 接受同空间已有回忆的 ID。关联保持回忆创建者及媒体归属。一条回忆可以被多个计划引用，每个计划最多有一条关联。
- `POST /api/v1/shared-plans/{planId}/memory` 使用原有回忆创建字段与照片校验。回忆、修订、照片绑定、关联和审计在同一事务提交。详情返回 `memory_id`，未关联时为 null。
- 仅完成计划可以首次关联。数据库外键约束同空间关系，主键限制每个计划一条关联。持锁顺序为成员、33024 幂等键、33022 计划、33018 有序照片锁。新增关联守卫重入已持有的锁，转换路径不获取既有回忆的锁。
- 已有回忆关联的同键重放比较目标回忆。转换复用回忆创建的规范化指纹，并把计划 ID 纳入指纹。两个操作各自分类；同键不同内容拒绝。普通回忆创建路径不需要计划锁。
