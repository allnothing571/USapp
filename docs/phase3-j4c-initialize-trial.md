## 1. 初始化协议

新增 `tools/j4c_initialize.py`。独立 SetupClient 只接受 head/current、bootstrap/current 的已绑定规范载荷，拒绝普通行写入、更新及普通范围接口；普通运行客户端仍不接受 bootstrap 行。SetupClient 的限制是客户端协议，不是不可绕过的身份权限证明。

初始化先检查表参数，再在同一个元数据事务中用全分区范围查询探测任意行，第一列固定日志身份，后两列使用无穷边界，最多取一行。**不是枚举已知 row_type**，未知类型也会阻止新建；没有行但有继续标记/部分结果也不能当空分区。

真正空分区中，只以不存在条件插入零 head 和 bootstrap/current，然后在同一事务提交。回执含版本、日志身份、配置摘要、确定性初始化 UUID（Universally Unique Identifier，通用唯一标识符）及初始 head。没有对象存储调用或文字擦除。

非空时只允许匹配同一配置的原回执重放，且当前 head 必须存在并通过结构/身份检查。重放写入零行，**不把已推进的 head 改回零**。只有零 head 没有回执、未知行、不同配置回执、丢失/损坏 head 都不能修复或回填。提交回执丢失保持 UNKNOWN，不自动 Abort；后续新进程可以读取原回执确认初始化事实。

重放只确认原初始化事实，不验证当前完整对象链和索引有效，也不保证新 lineage 的真实性。发布/恢复读取仍需完整链检查，真实首次初始化还必须验证账号、资源、新日志身份及停止其他写入者。运行凭据有原始写权限时可绕过客户端规则，回执不是密码学认证或防管理员攻击措施。

对外的 initialize/Trial.initialize 工作进程入口固定合成凭据，默认禁止网络，只支持显式自建回环测试。低层 initialize_client 是受信任的注入协议，不能把它当成云权限校验或不可信代码沙箱。没有 live 模式、凭据加载器或真实资源初始化命令。将来独立初始化身份应只获所需表描述、行读、范围读、PutRow 和局部事务控制，不包含 UpdateRow、对象或资源管理权限；实际策略和授权尚未创建/应用。

## 2. 本地试验会话与限额

新增 `tools/j4c_trial.py`。Trial 在显式目录中独占创建以配置摘要命名的 SQLite 文件。父会话保持存活，工作进程共享文件中的计数；已有、部分、缺失、错误 nonce 或损坏账本均不能在运行调用里自动重建或修复。没有父进程重启后的恢复接口，不能删除文件或换目录来声称旧额度重新有效。

Trial.initialize 确认原初始化回执后，父会话才允许 Trial.publish；未知初始化须先重试确认。配置被修改后拒绝调用。这个门槛仅用于测试会话，**不是 J3 的数据库恢复/启动屏障**。

| 项目 | 固定上限/规则 |
|---|---|
| 不同操作 | 10；同键同规范载荷重试不新增，不允许重新绑定 |
| 每操作阶段 | 最多两种；实际语义仍由发布模型判断 |
| 网络请求尝试 | 5000，含描述、读取、事务控制及失败尝试 |
| 对象 PUT 尝试 | 20，含重试和未引用候选；比 20 个成功批次更保守 |
| 对象 PUT 请求体 | 累计 2 MiB |
| 全部请求体 | 累计 8 MiB；不是全部网络包大小 |
| 接收响应体 | 累计 64 MiB，含尚未结算的保守预留 |
| 会话窗口 | 2 小时单调时钟；倒退/到期拒绝进入调用 |
| 每工作进程调用 | 最多 5 秒并受剩余会话窗口约束；保留既有回收预算 |

发送前先提交本地请求/字节预留，再进行网络操作，SQLite 事务中不持有网络调用。失败和丢回执不退请求/上传额度。读取前预留本次最大读取量；成功读到明确字节数后一次性归还未使用部分。读取失败、进程被终止或结算不明确时保留预留量，重结算被拒绝。

初始化和发布走同一会话账本。额度耗尽时连 Abort 也可能无法补发，远端未提交事务可能等待服务端失效；不能声称已回滚或强行给 Abort 绕开额度。测试明确观察了这类假事务仍未结束，真实服务端过期尚未验证。

这些限制不是自动止付、费用保证、总网络流量或容量单元计量。请求头/加密开销不在体字节计数里；资源存储仍可能继续收费。本地文件也不是外部删除日志或防恶意管理员计量器，未验证断电耐久性；人工改写、换目录、损坏及系统重启仍需按停止试验/人工核对处理。普通未计量离线辅助入口保留兼容，但不能作为真实试验入口使用。
