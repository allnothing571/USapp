## 门槛、凭据与截止

默认不读取/检查凭据路径、依赖路径或状态目录，不创建账本、不联网。真实入口同时要求 `--run --ack-synthetic-cloud-writes --ack-fresh-empty-journal` 和外部私有凭据文件、固定临时依赖位置、明确的全新状态目录。开关记录操作意图，不能代替用户的实际授权。上一步批准了离线开发；本批尚未授权执行实际初始化/写入。

继续复用 Win32 文件句柄/权限检查、绑定摘要、三组独立密钥和本地两小时有效窗口。密钥仅通过内存交给自有子进程，不写 argv、环境变量、证据或控制台。每个阶段开始均检查本地有效期，传输前还有单调时钟试验窗口检查。永久云密钥不会因本地窗口结束自动失效。

每阶段固定 5 秒整体预算，父进程只回收其自有子进程，不能提供操作系统硬实时保证。SDK 和 HTTP 层不自动重试或跟随重定向，验证证书和主机。发布器只允许一轮，不在 head 竞争后重建候选并重试。任何未知、冲突、超时、未回收或证据写入失败均停止；不进入下一阶段，不自动重试、恢复、清理、换目录或重置预算。

未知提交可能已经写入云端；未收到初始化答复时尤其不能重新初始化。中止失败也可能留下事务租约。已确认 intent 后若后续失败，合成意图可能保持未决；需查看精确证据后单独设计恢复，不能宣称未发生写入。

## 权限与试验配额

发布对象用 object-publisher；检查点及初始化用 checkpoint-writer；检查点验证器用自己的 writer 密钥读取对象，不能借用发布者密钥；最终回读用 recovery-reader。恢复侧表传输仅允许 Describe/Get/Start/Abort，不能写入/提交。初始化侧不允许 UpdateRow；整个入口拒绝 DeleteRow、对象删除、其他主机/路径/管理接口。

复用 Trial/Ledger，未更改旧离线入口：最多 10 操作、各两阶段、5000 请求、20 对象 PUT 尝试、2 MiB 对象上传体、8 MiB 请求体、64 MiB 接收、单调时钟两小时窗口。本入口本身固定一操作、两候选批次，不开放更大参数。配额在网络前预扣；不确定结果不退还。这些数值不是 5 元自动账单上限，不包含其他程序、账号其他资源或实例长期费用。

状态目录必须从未存在，SQLite 创建一次；不支持父进程重启或续跑。用户手工另建目录可以绕过本地累计限制，本入口不能替代云账号预算管理。

## 本地证据与清理边界

状态目录保存 trial-evidence.json 和 trial-<manifest>.sqlite3：合成操作、各阶段固定枚举结果、候选对象键、请求/字节配额、completed=false/true，始终 serving_allowed=false、cleanup_performed=false。不保存凭据、原始云响应或异常文本。

候选对象键在 PUT 前记录到同一 SQLite。它可能指向未发送或不存在的对象，但不会遗漏已执行到该路径的 PUT 候选。正常阶段及已回收失败后导出；配额窗口结束仍可只读导出，不修改或恢复预算。若进程异常退出，JSON 可能滞后，SQLite 必须保留，不能仅按 JSON 清理。另一个进程可改变本地文件、磁盘失败或主机管理员恶意行为不在保证内。

没有删除代码或自动清理命令。实际运行后的桶对象、表行、资源、策略和密钥处理需按确切清单及独立授权进行；先保留证据，不复用旧媒体桶或旧密钥。基础试验无保留锁，不能声称对象云端不可覆盖。
