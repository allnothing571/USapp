## 1. 入口和权限边界

`tools/j4c_publication_worker.py` 的 `publish()` 固定使用合成测试凭据，所有普通调用默认传输阻止网络；没有 live 模式、凭据文件参数、环境变量启用开关或任意目标函数参数。只允许通过内部测试 Fixture 将固定资源端点路由至明确的回环端口。Fixture 不是云访问授权，也不是独立所有权证明。

主进程先检查配置、规范化并复制操作，限制大小和阶段，然后启动工作进程。工作进程从头创建 SDK 客户端，DescribeTable 后检查表参数并 Start/Abort 探测局部事务能力，然后执行完整 Publisher 流程。对象调用仍在元数据事务外。整次调用由既有 `j4c_call_deadline.run` 包围；子进程回收不代表远端事务回滚。

返回只含状态、是否超时、工作进程是否回收；`proven_not_applied` 和 `serving_allowed` 永远 false。无效输入在启动前拒绝，不能据此推断历史同键请求未生效。提交响应丢失或工作进程被终止，都不能自动 Abort 或推断未写；后续新进程沿原操作和载荷读取规范链及索引，确认原结果。

本地传输在 `tools/j4c_local_transport.py`：只使用单个显式指定的 127.0.0.1 端口、固定合成证书主机名，禁止其他连接及外部域名解析；测试信任只在连接池中注入。该传输不是生产后门或正式云传输。工作进程不读取合成私钥，服务端仅从本轮生成目录读取它。

同时把 SDK 传输改为拒绝压缩响应并禁止自动解压，保留大小上限、签名、摘要及禁用重试。新增拒绝用例走真实 SDK 加密连接，描述响应被拒绝后不进行发布。

## 4. 空日志初始化与创建前门槛

当前入口**没有初始化功能**，缺失 head 停止；测试直接预置 head，不是初始化协议验收。创建准备必须按以下顺序单独落地：

1. 确认实际账号身份，选择新随机运行后缀及新日志身份，列出确切名称和测试窗口；不复用已有媒体桶或相似名字资源。
2. 给所有者具体配置、5 元人工停止阈值、角色与费用范围、确切收尾清单，另获创建授权。预算不是自动止付。
3. 获准后由独立设置身份验证账号/资源所有权、继承权限、桶私有且版本控制从未启用、无生命周期/复制/锁；验证表结构、参数及局部事务。不能用本工具的格式通过代替这些证据。
4. 保持运行写入者关闭，核对新日志整个分区（含未知行类型）确实为空；单独的初始化器在事务内重检 head、批次及所有索引，再条件插入零 head。其他服务存储检查在事务外。不可把丢失 head、非空分区、恢复出的旧检查点或既有删除周期当作新空日志处理；遇到这些必须停止。
5. 保留独立可核验的初始身份与检查点记录，核对运行身份只获得精确资源范围所需权限；之后才进行最小实际存储试验。具有 UpdateRow 的身份可以绕过客户端改写 head，不能把权限范围收窄当作单调更新或防回退证明。独立当前检查点证据及相应防回退方案仍需设计和验收，不由配置摘要解决。

以上为待实现/待验收的协议，不是本批已执行动作。真实初始化、实时云传输/凭据管理和实际资源创建均不在本批。
